# PC CLUB — первая версия

Локальное учебное приложение на C# и ASP.NET Core MVC. Визуальное направление основано на выбранном референсе INVASION; используются собственная вёрстка и сгенерированные для проекта изображения.

## Запуск

В Visual Studio откройте `PcClub/PcClub.slnx`, выберите профиль **http** и запустите проект. Другой способ из папки проекта:

```powershell
.\Start-Site.ps1
```

Если выполнение локального скрипта запрещено настройками компьютера, выполните без изменения этих настроек:

```powershell
dotnet run --project PcClub/PcClub.csproj --launch-profile http
```

Адрес: **http://localhost:5089/**. Если сайт уже работает, достаточно открыть адрес; второй экземпляр на том же порту запускать не нужно.

Нужны установленный .NET 10 и работающий SQL Server `MARKOVINI`, настроенные ранее на этом компьютере. Подключение находится в `PcClub/appsettings.json`, используется текущая учётная запись Windows. При переносе проекта измените имя сервера под свой компьютер. Доверие сертификату настроено только в строке локального подключения, системные настройки сертификатов не меняются.

При первом запуске приложение применяет EF Core migrations, создаёт базу `PcClub`, роли и демонстрационный каталог. Существующие данные при повторном запуске сохраняются. Если каталог уже наполнен, начальные услуги повторно не создаются.

## Что работает

- Главная: переключение игровых зон с клавиатуры и мышью, оснащение, преимущества, галерея интерьера.
- `/services`: каталог и фильтр категорий; `/services/{id}`: карточки услуг.
- `/contacts`: контактная информация из настроек приложения.
- `/account/register`, `/account/login`: регистрация, вход и выход через Identity.
- `/admin`: добавление, изменение и удаление услуг и категорий; загрузка JPEG, PNG, WebP до 4 МБ.
- `/api/services`, `/api/services/{id}`: JSON из той же базы; фильтр `?categoryId=...`, ответы 200 и 404.
- Одна категория содержит несколько услуг, связь хранится как внешний ключ.

Пароль: минимум 10 символов, без обязательных цифр, спецсимволов и смешанного регистра; повтор должен совпадать. Обычная регистрация всегда создаёт роль User и не предоставляет доступ в админку.

## Первый администратор

На этом компьютере откройте **http://localhost:5089/setup** и задайте собственные email и пароль. Пароля администратора в исходниках нет.

Начальная настройка доступна только в режиме Development с локального адреса и только пока не создан первый администратор. После этого она возвращает 404. Стандартная регистрация продолжает создавать обычных пользователей. В Production страница настройки отключена. Облачная версия опубликована: https://pc-club.layero.app/; устройство и повторная публикация описаны в [docs/LAYERO.md](docs/LAYERO.md).

## Данные и материалы

В базе первоначально 3 категории и 4 услуги. Тарифы и оборудование демонстрационные; реальные адрес, телефон и график клуба пока не предоставлены. Их можно заполнить в разделе `Club` файла `PcClub/appsettings.json`. Изображения — концепции интерьера, а не фотографии действующего клуба.

Фото для новых услуг сохраняются в `PcClub/wwwroot/uploads`. Для переноса пользовательского наполнения нужны и резервная копия SQL-базы, и эта папка. Она исключена из Git, но не удаляется приложением автоматически при удалении услуги.

Онлайн-бронирование и оплата не подключены. Все основные кнопки ведут в действующий каталог или на страницу контактов.

## Структура и проверка

- `Models`: сущности, базовый класс, модели форм.
- `Data`: контекст SQL Server, миграции и начальное наполнение.
- `Services`: интерфейс и реализация доступа к каталогу.
- `Controllers`: публичные страницы, аккаунт, админка и API.
- `Views`: Razor-представления; `wwwroot`: стили, JavaScript, изображения и шрифты.
- [Структура сайта](docs/SITE-STRUCTURE.md), [дизайн-система](docs/DESIGN-SYSTEM.md), [происхождение и стоимость изображений](docs/GENERATED-ASSETS.md).

```powershell
dotnet build PcClub/PcClub.csproj --no-restore
```
