# Публикация PC Club

Отдельный проект: `pc-club`, организация `slavaprime98`.
Адрес: https://pc-club.layero.app

Приложение остаётся на C# / ASP.NET Core MVC. Сервер собран для Linux x64 с собственным .NET и ICU. Небольшой Node launcher запускает его в контейнере Layero. Он слушает `0.0.0.0:$PORT`.

## Данные

Локальная версия использует прежнюю базу SQL Server `PcClub`. При наличии `LAYERO_DATABASE_URL` включается PostgreSQL. В существующей базе Layero используются отдельные таблицы в схеме `pcclub`. Перенесены каталог, аккаунты с хэшами паролей и роли. Пароли не менялись; действующий администратор сохраняет доступ. Для TLS используется `VerifyFull` с проверкой имени сервера и официальным корнем ISRG Root X1 в `PcClub/certs/isrgrootx1.pem` ([инструкция Layero](https://docs.layero.ru/en/database/connect/)).

В облаке загружаемые через админку изображения хранятся в `pcclub.StoredImages` и доступны по `/media/{id}`. Ключи сессий сохраняются в `pcclub.DataProtectionKeys` в зашифрованном виде. Перезапуск контейнера не удаляет эти данные. Локальные загрузки по-прежнему сохраняются в `wwwroot/uploads`.

Настройки хостинга: `ASPNETCORE_ENVIRONMENT=Production`, автоматически подключённый `LAYERO_DATABASE_URL` и секрет `CloudKeyCertificate`. Значения секретов не записаны в проект. Не заменяйте сертификат без плана переноса старых ключей: это завершит активные сессии. Сохраняйте его при резервном копировании вместе с базой.

Вход: `/account/login`, админка: `/admin`. Начальная настройка `/setup` в интернете закрыта. Новая регистрация создаёт обычного пользователя.

Динамические страницы и перенаправления входа имеют `private, no-store`, `Vary: Cookie` и `X-Accel-Expires: 0`, чтобы кеш хостинга не сохранял отказ в доступе одного пользователя для остальных. Перенаправления входа относительные и сохраняют публичный HTTPS.

## Повторная публикация

1. Из корня проекта выполните `./Build-Layero.ps1`.
2. Перейдите в `.setup/layero-deploy`.
3. Проверьте план: `npx layero@latest deploy --dry-run --project dfb7214b-758b-4389-8ad4-7274ea01ed1c --json`.
4. Опубликуйте: `npx layero@latest deploy --project dfb7214b-758b-4389-8ad4-7274ea01ed1c --yes --json`.

Публиковать нужно только подготовленную папку. Корневая `.setup` содержит установщики и служебные материалы, которые сайту не нужны. Скрипт сборки удаляет локальную строку подключения из пакета.

Демонстрационные тарифы, AI-изображения и незаполненные контакты сохраняются. Бронирование и оплата не подключены.
