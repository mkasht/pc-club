# Дизайн-система PcClub

Дата: 27 октября 2026 года. Спецификация визуального направления и основа первой вёрстки ASP.NET Core MVC.

В первой реализации подключены локальные шрифты **Oswald** для заголовков и **Manrope** для текста, с сохранёнными лицензиями. Фактические размеры и адаптивные правила находятся в `PcClub/wwwroot/css/site.css`. Ниже сохранены исходные измерения референса и предложенные токены; пример с Arial — первоначальная схема, а не текущие шрифты сайта.

Референс: [INVASION](https://invasion.ru/). Это спецификация собственного сайта в близком визуальном направлении. Логотип, тексты, фото и видео клуба должны быть собственными или предоставленными с правом использования.

## 1. Направление

Почти чёрный фон, большие фотографии пространства, крупные узкие заголовки, светлые овальные кнопки и минимум рамок. Яркие цвета приходят из интерьера, а интерфейс остаётся монохромным. Чередуем полноширинные фотографии с компактными информационными блоками. Разделы не должны выглядеть одинаковой сеткой маленьких карточек.

На референсе проверены первый экран, блок зоны и мобильное меню. Параметры ниже с пометкой «измерено» получены из отображённой страницы и вычисленных CSS-стилей. Остальные — предлагаемые правила PcClub, а не сведения о реализации INVASION.

## 3. Токены: три уровня

**Примитивы** хранят исходные цвета, размеры и интервалы. **Семантические токены** задают роли: фон страницы, основной текст, граница. **Токены компонентов** связывают роль с кнопкой, полем или карточкой. В CSS компонентов используем эти переменные, чтобы настройки менялись в одном месте.

Предлагаемый стартовый набор:

```css
:root {
  /* Примитивы */
  --black: #000;
  --ink: #050505;
  --gray-950: #191919;
  --white: #fff;
  --white-90: rgba(255, 255, 255, .9);
  --white-65: rgba(255, 255, 255, .65);
  --white-10: rgba(255, 255, 255, .1);
  --space-1: 4px;
  --space-2: 8px;
  --space-3: 12px;
  --space-4: 16px;
  --space-5: 20px;
  --space-6: 24px;
  --space-8: 32px;
  --space-10: 40px;
  --space-16: 64px;
  --space-24: 96px;
  --radius-sm: 8px;
  --radius-md: 16px;
  --radius-pill: 999px;

  /* Роли */
  --bg-page: var(--ink);
  --bg-surface: var(--gray-950);
  --bg-floating: rgba(25, 25, 25, .9);
  --text-primary: var(--white-90);
  --text-secondary: var(--white-65);
  --text-on-light: var(--ink);
  --border-subtle: var(--white-10);
  --border-control: rgba(255, 255, 255, .4);
  --focus-ring: var(--white);
  --status-error: #ff9b9b;
  --status-success: #a8e6bd;
  --font-body: Arial, sans-serif;
  --font-display: "Arial Narrow", Arial, sans-serif;
  --container-max: 1440px;
  --container-gutter: 40px;
  --grid-gap: var(--space-5);
  --motion-fast: 150ms;
  --motion-normal: 250ms;
  --motion-ease: cubic-bezier(.4, 0, .2, 1);

  /* Компоненты */
  --button-primary-bg: var(--white-90);
  --button-primary-fg: var(--text-on-light);
  --button-secondary-bg: var(--bg-surface);
  --button-height: 56px;
  --button-radius: var(--radius-pill);
  --input-bg: var(--bg-surface);
  --input-border: var(--border-control);
  --input-height: 56px;
  --input-radius: var(--radius-sm);
  --card-bg: var(--bg-page);
  --card-border: var(--border-subtle);
}

@media (max-width: 767px) {
  :root { --container-gutter: 24px; }
}
```

Шрифты в этом фрагменте — системные временные замены. Для близкой пластики заголовков нужен настоящий узкий шрифт с кириллицей, а не искусственное сжатие текста. DIN подключаем только при наличии подходящей лицензии; окончательную замену и её лицензию проверим при подготовке макета. Без подключения выбранного шрифта совпадение типографики не гарантируется.

## 4. Типографика PcClub

| Роль | Компьютер | Телефон | Применение |
| --- | --- | --- | --- |
| Главный заголовок | 96–128 px / 0.95–1 | 48–64 px / 1 | Первый экран, короткая фраза в верхнем регистре |
| Заголовок раздела | 48–64 px / 1 | 36–40 px / 1.05 | Зоны, оснащение, контакты |
| Заголовок карточки | 28–36 px / 1.1 | 24–28 px / 1.15 | Название услуги |
| Вводный текст | 20–24 px / 1.35 | 18 px / 1.4 | Короткое описание клуба или зоны |
| Основной текст | 18 px / 1.5 | 16 px / 1.5 | Описания, формы, контакты |
| Подписи | 14 px / 1.4 | 14 px / 1.4 | Единицы цены, пояснения |

Предлагаемые размеры плавно интерполировать через `clamp()`. Для длинного текста ограничить строку примерно 60–70 знаками. Цены, адреса и формы не набирать целиком узким шрифтом в верхнем регистре. Проверить кириллицу, цифры и знак рубля в выбранном шрифте.

## 5. Сетка и адаптация

- От 1200 px: условная сетка 12 колонок, поля 40 px, промежуток 20 px; контентный контейнер до 1440 px. Фото первого экрана может выходить на всю ширину.
- 768–1199 px: 8 колонок, поля 32 px; описание зоны и характеристики переносятся в две строки или колонки.
- До 767 px: 4 колонки, поля 24 px; фото → название → описание → цена → действие. На очень узких экранах 320–359 px допустимы поля 16 px.
- Проверочные ширины: 360, 390, 768, 1280, 1440 px. Это предлагаемые контрольные точки, не измеренные брейкпоинты референса.
- Интервалы разделов: 96–128 px на компьютере, 56–72 px на телефоне. Внутри блока обычно 16–32 px.
- Первый экран: `min-height: 100svh`, без жёсткой фиксированной высоты; текст и кнопки остаются доступными при увеличении масштаба. На телефоне основные действия должны быть видны или явно доступны следующим блоком.
- Изображение зоны: широкий кадр на компьютере, более компактный на телефоне; важные предметы не обрезаются. Высоту задаём через `aspect-ratio`, положение кадра выбираем отдельно для каждого снимка.

## 6. Компоненты и состояния

| Компонент | Вид и поведение |
| --- | --- |
| Шапка / меню | Собственный логотип слева, круглая кнопка справа. Полноэкранное меню; заметная ссылка входа. При открытии фокус в меню, закрытие по Escape и возврат фокуса к кнопке |
| Основная кнопка | Светлая заливка, тёмный текст, высота 56 px, горизонтальные поля 28 px, овальная форма. Hover: более светлая заливка; active: лёгкое затемнение; focus-visible: внешняя рамка 2 px с отступом 3 px |
| Вторая кнопка | Тёмно-серая заливка, светлый текст. Состояния не зависят только от изменения цвета текста |
| Ссылка | В тексте подчёркнута; в меню текущий пункт выделен. Переходы — ссылки, действия — кнопки |
| Переключатель зон | Группа тёмных овальных элементов, выбранный — светлый. Для настоящих вкладок нужны роли tablist/tab/tabpanel, стрелки клавиатуры и видимый фокус; для переходов достаточно ссылок |
| Карточка услуги | Фото без тяжёлой тени, название, краткий текст, цена и ссылка. Hover не скрывает цену и не является единственным способом увидеть действие |
| Плашка характеристики | Компактная тёмная капсула; текст и единица измерения. Цена заметнее вспомогательных параметров |
| Поле ввода | Постоянная подпись сверху, тёмная поверхность, видимая граница. Focus: светлая рамка; error: текст причины рядом с полем; placeholder не заменяет подпись |
| Отправка формы | Состояние ожидания с текстом; защита от повторного отправления. Ошибки сервера сохраняют введённые допустимые значения |
| Галерея | Полноэкранный просмотр, подпись снимка, закрытие, предыдущий/следующий. Клавиатура, Escape, возврат фокуса |
| Админская таблица | Читаемые строки, явные действия «Изменить» / «Удалить». На телефоне — прокрутка самой таблицы или карточки записей |
| Уведомление | Ошибка или успех обозначены текстом и цветом; доступны вспомогательным технологиям |

Disabled-состояние формы визуально приглушено и действительно недоступно; рядом объясняется причина, если она не очевидна. Не использовать низкую прозрачность для обязательных подсказок и условий тарифа.

## 7. Фото, видео и движение

Нужны: один главный кадр, по одному качественному фото каждой зоны, 3–5 снимков интерьера и один кадр оснащения. Начать можно со статичного первого экрана; видео — улучшение после готовой адаптивной страницы.

Для видео нужен постер, приглушённый звук, возможность остановки и статичная версия при ограничении движения. Заголовок должен читаться на любом кадре: отдельный тёмный слой и проверка контраста. Не встраивать важный текст в изображение.

Hover-переходы 150 ms; появление блоков 200–300 ms, сдвиг до 16 px. При `prefers-reduced-motion: reduce` отключаем декоративное движение и автопрокрутку. Контент доступен без выполнения анимации; прокрутку не перехватываем.

Изображения подготовить в нескольких размерах с `srcset`, явно указать ширину и высоту, отложенно загружать материалы ниже первого экрана. Главное изображение загружать сразу. Форматы и вес проверить на реальных материалах; не загружать все фотографии полного разрешения при открытии страницы.

## 8. Условия готовности дизайна

1. Есть макеты главной и каталога для компьютера и телефона с одинаковыми компонентами.
2. Проверены состояния меню, выбранной зоны, пустого каталога, отсутствующего изображения, ошибок и успешной отправки формы.
3. Все функции доступны клавиатурой, фокус виден, меню не создаёт ловушку; управляющие области не меньше 44 × 44 px.
4. Контраст обычного текста не ниже 4.5:1, крупного — 3:1; контраст важных границ и индикаторов состояния также проверен. Низкую прозрачность референса не переносим автоматически на формы.
5. На 360 px нет горизонтального переполнения страницы, заголовки не обрезаются, увеличение масштаба не скрывает действия.
6. Кнопки ведут в существующие разделы; заполнение данных из БД не ломает карточки и переносы.
