# Проверка первой версии PcClub

Локальные проверки выполнены 27 октября 2026 года на http://localhost:5089/ с SQL Server. Затем сайт опубликован на https://pc-club.layero.app/ и прошёл ещё 25 облачных проверок; подробности находятся в [LAYERO.md](LAYERO.md).

## Сборка и база

- `dotnet build PcClub/PcClub.csproj --no-restore`: без ошибок и предупреждений.
- Создана миграция `InitialCreate`, схема применена к SQL Server.
- Независимый запрос SQL подтвердил 4 услуги, 3 категории и запись миграции.
- Повторные запуски приложения сохраняют каталог и не дублируют начальное наполнение.
- После функциональных проверок в базе не осталось временных QA-пользователей и записей; данные реальных пользователей не изменялись.

## Функциональные проверки — 37 успешно

Проверки выполнялись HTTP-запросами к настоящему работающему приложению, с формами Identity, анти-CSRF-токенами, cookie и настоящей SQL-базой.

- Публичные страницы, стили, JavaScript, главное изображение и шрифт отвечают 200.
- API возвращает каталог; отсутствующая услуга даёт 404 в API и на странице.
- Фильтр возвращает услуги только выбранной категории; проверена категория с несколькими услугами и пустой результат.
- Гость направляется на вход при обращении к админке; POST без анти-CSRF-токена отклоняется.
- Регистрация и вход работают. Пароль только из маленьких букв принимается при соблюдении длины; обязательных цифр и спецсимволов нет.
- Передача поля Role=Admin при регистрации не повышает права. Обычный пользователь не может открыть админку.
- Неверный пароль не допускает вход; внешний ReturnUrl после успешного входа игнорируется.
- Первоначальная локальная настройка создаёт администратора и затем отключается.
- Администратор создаёт и изменяет категории и услуги. Дробная цена с запятой сохраняется как decimal и корректно возвращается API.
- Созданная услуга появляется в публичном каталоге и на отдельной странице.
- SVG и файл больше 4 МБ отклоняются без сохранения сопутствующих изменений. JPEG сохраняется под новым именем и открывается по своему адресу.
- Категория с услугами не удаляется; несуществующая категория не принимается при сохранении услуги.
- Проверены удаление услуги, изменение категории и удаление пустой категории. После тестов исходный каталог остался прежним.

Временные пароли создавались только в памяти сценария проверки; готового административного аккаунта с общим паролем в проекте нет.

## В браузере

На ширинах **360, 768 и 1440 px** проверены главная, каталог, карточка услуги, контакты и регистрация: 15 сочетаний, без горизонтального переполнения страницы и с одним основным заголовком на каждой странице.

Дополнительно проверены:

- **390 × 844:** первый экран, меню, каталог, форма регистрации.
- **1280 × 800:** первый экран, каталог и блок зон.
- Переключение зон мышью и стрелками клавиатуры; открыта только выбранная панель.
- Галерея открывает выбранное изображение; Escape закрывает её и возвращает фокус к исходной кнопке.
- Мобильное меню открывается и закрывается по Escape, возвращает фокус к кнопке меню.
- Фильтр «Приватные комнаты» оставляет одну соответствующую карточку.
- В форме регистрации отображается новая подсказка о длине без требований к составу пароля.

## Что нужно перед использованием реальным клубом

Заполнить реальные контакты, тарифы и оборудование, заменить или подтвердить иллюстрации, создать личного администратора через `/setup`. Бронирование, оплата, восстановление пароля по почте и интернет-публикация в первую версию не включены. Email в аккаунте сейчас служит логином: отправка писем и подтверждение адреса не настроены.
